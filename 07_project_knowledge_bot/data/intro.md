# 项目简介

本项目是一个示例知识库，演示如何把私有文档接入 LLM 问答。

- 王五：前端工程师，负责 Web 界面

## 技术栈

- 后端：Python 3.11 + FastAPI + PostgreSQL
- 前端：React 18 + Tailwind CSS
- LLM 框架：LangChain 0.3 + LangGraph 0.2
- 向量库：FAISS（本地）/ Milvus（生产）
