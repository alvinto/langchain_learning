Checkpoint + HITL

LangGraph 生产特性

Checkpointthread_id · MemorySaver

每次 invoke 持久化 State；同一 thread_id 多轮共享 messages。

  • .compile(checkpointer=MemorySaver())
  • {"configurable": {"thread_id": "…"}}

Human-in-the-loopinterrupt_before

敏感步骤进节点前暂停，审批后 invoke(None) 续跑。

  • interrupt_before=["tools"]
  • 第一次 invoke 返回待审批 state

LangChain vs LangGraph · 第一性边界

选型 · 全链路 8 步

LangChain
无状态线性/分支 LCEL · 无持久全局 State · 简单固定流水线
LangGraph
全局 State + 条件循环/回退边 · 反思 · Multi-Agent · Checkpoint

边界：纯 LangChain = 链式工作流；真正自主 Agent 必须 LangGraph（或可恢复的 create_agent 封装）。

全链路 8 步（学习指南 §5）

① 用户输入 → ② RAG 检索长时记忆 → ③ 送入 Supervisor → ④ 拆分子任务 → ⑤ 调用工具 Agent → ⑥ 反思节点自查 → ⑦ 汇总输出 → ⑧ 短时 Memory + 长时入库

LangSmith & 学习路径

LangSmith 价值

  • Trace — 逐步查看 LCEL / Agent 每次 Runnable 调用与延迟
  • Debug — 对比 Prompt 版本、复现失败会话
  • Eval — 数据集回归评测，上线前守门

设置 LANGCHAIN_TRACING_V2=true 与项目名（见仓库 _common.py），本地示例即可在 LangSmith 看到完整链路与 Tool 回合。
